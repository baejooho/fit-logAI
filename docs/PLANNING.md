# FitLog AI — 기획서 및 요구사항 정의서

## 1. 프로젝트 비전

헬스장을 다니는 본인을 위한, 매번 같은 운동만 반복하는 문제를 해결하는
AI 기반 운동 루틴 생성 웹 서비스를 만든다.

목표(벌크업·다이어트·체력유지)와 경험 수준, 운동 가능 일수, 집중 부위,
신체 정보, 추가 요구사항을 입력하면 AI가 점진적 과부하가 반영된 1주
운동 루틴을 생성해준다. 운동 후 실제 수행한 무게(kg)를 기록해두면,
다음 주 루틴 생성 시 AI가 이 기록을 참고하여 점진적 과부하를 자동으로
반영한 새로운 루틴을 만든다.

## 2. 문제 정의 (본인 경험 기반)

- 헬스장에 가도 항상 같은 운동만 반복하게 되어 점점 지루해지고,
  결국 헬스 자체를 안 가게 되는 경험을 했다.
- 새로운 운동을 시도해보고 싶지만 무엇을 해야 할지 모른다.
- PT는 월 수십만 원으로 비용 부담이 크다.
- 운동 기록(무게, 세트, 횟수)을 직접 보관하고, 다음 계획에 반영하고 싶다.

## 3. 핵심 요구사항 (기능 요구사항)

| ID | 요구사항 | 설명 |
|----|----------|------|
| FR-1 | 목표 선택 | 벌크업/다이어트/체력유지 중 선택 |
| FR-2 | 경험 수준 입력 | 초보/중급/고급 중 선택 |
| FR-3 | 운동 가능 일수 입력 | 주당 2~7일 설정 |
| FR-4 | 집중 부위 선택 | 상체/하체/전신 중 선택 |
| FR-5 | 신체 정보 입력 (선택) | 키, 몸무게 |
| FR-6 | 추가 요구사항 입력 (선택) | 자유 텍스트 (예: 무릎 부상으로 스쿼트 대체, 덤벨만 사용 등) |
| FR-7 | AI 루틴 생성 | 입력값 기반 1주 점진적 과부하 루틴을 JSON으로 생성 |
| FR-8 | 결과 시각화 | 요일별 탭으로 운동 이미지, 세트×횟수, 휴식시간, 예상 소요시간, 종목수, 총 세트 표시 |
| FR-9 | 수행 무게 기록 | 운동별로 실제 수행한 무게(kg)를 입력·저장 |
| FR-10 | 루틴 저장 | 생성된 루틴(+수행 기록)을 routines.json에 저장, 최대 20개 |
| FR-11 | 이전 루틴 조회/삭제 | 저장된 루틴 목록 조회 및 삭제 |
| FR-12 | 요일 자동 반영 | 접속 시 오늘 요일에 해당하는 탭이 자동 선택 |
| FR-13 | 다음 주 루틴 생성 (점진적 과부하) | 이전 루틴의 기록된 수행 무게를 AI 프롬프트에 포함하여, 점진적 과부하가 반영된 다음 주 루틴을 생성. 목표/경험/부위 등 입력값 재설정 가능 |

## 4. 비기능 요구사항

- 환경변수 관리: GEMINI_API_KEY 등 민감 정보는 `.env`로 관리, 저장소 미포함
- API 비용 효율성: 1회 호출당 1주 분량만 생성하여 토큰 사용 최소화
- 1인 사용 최적화: 별도 DB 설치 없이 JSON 파일 기반 저장
- 테스트: 핵심 저장 로직(db.ts)과 서버 응답(web.ts)에 대한 자동화 테스트 보유 (단위 1개, 통합 1개, 모두 PASS)
