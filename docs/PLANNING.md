# FitLog AI — 기획서 및 요구사항 정의서

## 1. 프로젝트 비전

헬스장을 이용하는 누구나, 자신의 목표(벌크업·다이어트·체력 유지)에 맞는
운동 루틴을 AI가 즉시 설계해주는 웹 서비스를 제공한다.

기존에는 유튜브 루틴(내 몸 상태 미반영), PT(고비용), 직접 짠 루틴(점진적
과부하 미반영) 중 하나를 선택해야 했다. FitLog AI는 사용자의 목표·경험·
운동 가능 일수를 입력받아, AI가 한 주간의 점진적 과부하 운동 루틴을
자동으로 생성하여 이 문제를 해결한다.

## 2. 문제 정의

- 헬스장 이용자는 "오늘 무엇을 해야 하는가"에 대한 답을 얻기 어렵다.
- 일반화된 루틴은 개인의 목표와 경험 수준을 반영하지 못한다.
- 점진적 과부하(progressive overload) 개념을 적용한 루틴을
  스스로 설계하기는 진입 장벽이 높다.
- 전문가(PT)의 도움을 받으려면 비용 부담이 크다.

## 3. 핵심 요구사항 (기능 요구사항)

| ID | 요구사항 | 설명 |
|----|----------|------|
| FR-1 | 목표 선택 | 사용자는 벌크업/다이어트/체력유지 중 하나를 선택한다 |
| FR-2 | 경험 수준 입력 | 초보/중급/고급 중 선택한다 |
| FR-3 | 운동 가능 일수 입력 | 주당 운동 가능 일수를 입력한다 |
| FR-4 | AI 루틴 생성 | 입력값을 기반으로 AI가 1주 점진적 과부하 루틴을 생성한다 |
| FR-5 | 결과 시각화 | 생성된 루틴을 요일별 표 형태로 웹에 표시한다 |

## 4. 비기능 요구사항

- 응답 시간: AI 루틴 생성 요청 후 수 초 내 결과 반환
- 환경변수 관리: API 키 등 민감 정보는 `.env`로 관리하고 저장소에는 포함하지 않음
- API 비용 효율성: 무료 티어 한도 내에서 동작 가능하도록 1회 요청당
  생성 범위를 1주 단위로 제한
- 확장성: 추후 DB 연동, 다주차 플랜, 식단 추천 기능을 추가할 수 있는 구조

## 5. 향후 확장 계획 (Future Work)

- SQLite DB를 활용한 사용자별 루틴 저장 및 히스토리 관리
- 1주 루틴을 누적하여 4주 점진적 과부하 플랜으로 확장
- 매 운동 기록을 입력받아 다음 루틴에 반영하는 적응형 추천 기능
- 칼로리·단백질 목표 기반 식단 추천 기능
